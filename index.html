ECE Skill Trees

Domain Skill-Tree Roadmaps

Referenced from ECE Lab (ecelab.me) & industry standards. Select a specialization domain to view the ordered learning path from fundamentals to buildable projects.

🔌 Embedded Systems & Firmware Skill Path

5 PHASES · CORE ECE HARDWARE
PHASE 01

C / C++ Foundations

Pointers, memory management, bitwise operations (&, |, ^, ~), structs, and header files.

PHASE 02

Microcontroller Architecture

ARM Cortex-M, ESP32, RP2040. Timers, GPIOs, Interrupts (NVIC), and PWM generation.

PHASE 03

Register-Level Bare-Metal

No HAL / CubeIDE clicking — write directly to `GPIOA->ODR` using `arm-none-eabi-gcc` and Makefiles.

PHASE 04

Communication Protocols

Master UART, SPI, I2C, CAN Bus (automotive/EV), and USB CDC/HID device descriptors.

PHASE 05

FreeRTOS & Embedded Linux

Task queues, mutexes, semaphores, Yocto Project, and building Linux kernel device drivers.

📟 VLSI & Microchip Design Skill Path

5 PHASES · SEMICONDUCTOR & ASIC
PHASE 01

Digital Logic & FSMs

Boolean algebra, combinational adders/muxes, flip-flops, Mealy vs Moore state machines.

PHASE 02

Verilog & SystemVerilog

RTL coding guidelines, blocking vs non-blocking assignments, parameterized testbenches.

PHASE 03

Verilator & cocotb Verification

Constrained-random testing in Python with cocotb and high-speed C++ simulation via Verilator.

PHASE 04

5-Stage RISC-V CPU Core

Build a pipelined RV32I CPU core with hazard detection, forwarding unit, and Spike co-simulation.

PHASE 05

Synthesis & OpenLane ASIC

FPGA synthesis in AMD Vivado / Yosys, STA timing analysis, and OpenLane RTL-to-GDSII flow.

🤖 Robotics, Autonomous Vehicles & ROS 2 Skill Path

5 PHASES · AUTOMATION & AI
PHASE 01

Motor Drivers & Kinematics

H-bridge motor drivers (L298N, Cytron), quadrature encoders, PID control, and differential kinematics.

PHASE 02

Microcontroller Robot Build

Build an ESP32 Bluetooth robot or Pi Zero 2W differential drive teleoperation platform.

PHASE 03

ROS 2 & Gazebo Simulation

ROS 2 nodes, topics, services, publisher/subscriber patterns, and URDF robot simulation in Gazebo.

PHASE 04

SLAM & Nav2 Navigation

2D RPLidar SLAM mapping (`slam_toolbox`), AMCL localization, costmaps, and Nav2 path planning.

PHASE 05

Edge Computer Vision

OpenCV image processing, line tracking, object detection with YOLOv5n on ESP32-CAM or Jetson.

📶 IoT, PCB Layout & Hardware Skill Path

4 PHASES · HARDWARE & ELECTRONICS
PHASE 01

Analog & Circuit Simulation

Op-amps, active filters, transistor biasing, voltage regulators, and SPICE simulation in LTspice.

PHASE 02

KiCad Schematic & PCB Layout

Design custom PCBs in KiCad, trace routing, ground planes, DRC checks, and Gerber file generation.

PHASE 03

Wireless Protocols & Dashboards

Bluetooth LE, Wi-Fi 6, MQTT protocol, Node-RED, and cloud IoT dashboards (ThingsBoard / AWS IoT).

PHASE 04

Automotive & EV Electronics

CAN bus sniffing, OBD-II vehicle diagnostics, and Field-Oriented Control (FOC) for BLDC electric vehicle motors.
